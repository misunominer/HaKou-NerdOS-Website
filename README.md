# Ha•Kou NerdOS Website — Living UI v5

This build is a full website revision based on the current Ha•Kou NerdOS v2.3.3-beta project flow.

Highlights:
- Responsive hero with Chappī integrated on mobile.
- English / Portuguese / Japanese language selector.
- Captive Portal setup walkthrough based on the real NerdOS WiFiManager flow.
- Includes the customized post-save screen explaining how to find the new IP in the router using the configured Worker hostname and `hakou-<worker>.local`.
- Interactive simulated Live Dashboard (clearly marked as fictitious data).
- Real Home / Fleet / Configuration / OTA screenshots supplied from the current project.
- Pool behavior remains pool-independent; the demo never hard-codes a real pool or wallet.
- No external animation libraries.

Open `index.html` in a browser or deploy the folder to a static host.
